# Les fichiers du logo Glisil

| Fichier | Pour quoi |
|---|---|
| `glisil-logo.svg` | Le logo complet (comète + nom), sur fond clair. Le logo par défaut. |
| `glisil-logo-blanc.svg` | Le logo complet en blanc, sur le vert ou un fond sombre. |
| `glisil-icone.svg`, `glisil-icone-1024.png` | L'icône : le carré vert, la comète blanche et or. Magasins, réseaux sociaux, favicon. |
| `glisil-symbole.svg`, `glisil-symbole-blanc.svg` | La comète seule. |
| `glisil-nom.svg`, `glisil-nom-blanc.svg` | Le nom seul, vectorisé. |
| `xafe/xafe-jeton.svg`, `xafe/xafe-{32,64,100,256,512,1024}.png` | Le **jeton XAFe** : disque vert, X blanc, la pièce d'or au croisement. Pour BscScan, Tronscan, les wallets ; l'application montre le même. Produits par `jeton.py` et `jeton-png.mjs`, publiés sous `app.glisil.com/xafe/`. |

Le nom est vectorisé depuis Sora 700 par `logos.py` : les fichiers s'ouvrent
partout sans la police. Les règles d'usage (couleurs, marges, tailles, ce qu'on
ne fait pas) sont dans `docs/MARQUE.md` et dans le livret de marque.
